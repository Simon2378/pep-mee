Batch Numbers and COAs: Making Sure the Paperwork Matches Your Vials

A certificate of analysis is only meaningful for the batch it was written for. This guide covers how batches work, how to match paperwork to the vials in front of you, and what to ask a supplier.

Published by Care Peptides on 11 Jul 2026 · Last reviewed 5 Nov 2026

Quick answer

Each production run of a peptide gets a batch (lot) number, and each COA reports test results for one batch. When your order arrives, check that the lot number printed on the vials matches the lot number on the COA. If they don't match, the certificate describes a different batch, so ask for the right one.

Key takeaways

  • One batch, one COA: Results from one batch don't automatically carry over to the next.
  • Check the lot on arrival: Compare the vial label with the COA as soon as your order lands.
  • Keep it together: File the COA with your order details and lot number for your records.

What a batch is

Peptides are made in production runs. Everything from one run (synthesised, purified and freeze-dried together) shares a batch or lot number. Two batches of the same product can differ slightly in purity, peptide content or appearance, which is exactly why COAs are issued per batch.

Matching paperwork to vials

  1. Find the lot number on the vial label or pack.
  2. Find the lot number on the COA header.
  3. Check the product name and strength match too: a 5mg and a 10mg pack of the same peptide can come from different batches.
  4. Note the test date. Very old test dates are worth asking about.

In-house vs independent testing

A COA can come from the manufacturer's own quality-control lab or from an independent third-party lab. Both are common. Independent testing adds a second, separate check. In-house COAs are standard practice across the industry. Either way, the document should name who performed the tests and how. If a certificate doesn't say who tested it, ask.

About COA previews on our site

Where we have a certificate for a product series, we show a preview on the product page so you can review it before ordering. Previews show the batch that was documented at the time. If you need the certificate for the specific batch you'll receive, mention it when you order and we'll tell you what's available.

What to keep on file

For each order, keep the product and SKU, quantity, date received, lot number from the vials, and a copy of the matching COA. If a question comes up later, you'll be able to trace it to an exact batch.

Frequently asked questions

Does a new batch need a new COA?

Yes. Each batch is tested separately, so each should have its own certificate.

Where do I find the lot number?

On the vial label or outer pack, usually marked “Lot”, “Batch” or “LOT”. It's also in the header of the COA.

Can I get the COA for the exact batch I'm buying?

Ask when you order. Message Kyle with the SKU and we'll tell you which batch documentation is available.
